# vinayakcm.com redesign

Mockups and figure builds for the new portfolio. Everything is static HTML; open a file in Chrome or Safari.

## Where things are

| Path | What it is |
|---|---|
| `mockups/index.html` | Index of the current mockup |
| `mockups/v14/` | **Current site**: centered intro, 2x2 work grid, About; the robot's screen is the avatar (draggable, docks in a corner, morphing expressions) |
| `mockups/v13/` | Intro, work and About with the robot revealed in stages (screen, peeking over the grid, sitting on the card) |
| `mockups/v12/` | Intro + 2x2 work grid, no robot |
| `mockups/v11/` | VCM-03 robot (monochrome, front view, live gears, grabbing hands) and the homepage hosting him |
| `mockups/v9/`, `mockups/v10/` | Earlier robots (VCM-01, VCM-02) |
| `mockups/v8/` | Five object-led sites (meter, plotter, type cabinet, mill, lamp) |
| `mockups/v1`–`v7` | Earlier rounds of direction |
| `.claude/skills/anatomy/` | The [Anatomy](https://skills.wheresryan.sh/anatomy) skill (MIT) that the robot and figure builds import |

## Rebuilding a figure

The robot and object pages are generated by Node scripts (Node 20.10+):

```bash
node mockups/v13/build.mjs
node mockups/v11/robot/build.mjs
```

`mockups/v14/index.html` is hand-written and needs no build.
